# 前端布局优化与验证记录

日期：2026-10-30。基于 `main` 的 `6a2d1e0` 实施。

## 改动

- 浅色侧栏、顶部标题/项目/账号分区，以及独立运行状态栏；统一卡片、表格、工具栏和页面间距。
- 桌面导航支持折叠记忆，平板可展开，手机采用抽屉导航，支持背景隔离、焦点限制、Escape 关闭和焦点恢复。
- 区分普通长页面与全高工作区，修正内容被撑高、长内容被截断和筛选操作越界的问题；表格保留内部横向滚动。
- 用例、套件、缺陷共用目录宽度调整逻辑，默认 240px；修正拖拽偏移，支持方向键、Home/End 调整。
- APP 概览指标采用均衡网格；场景编排按可用内容宽度排列，草稿表单支持窄屏；登录注册采用与管理后台一致的浅色布局。
- 新增 `workspace-theme.css` 统一工作台样式入口，停止加载两份 QDesk 覆盖样式，移除主布局内重复的样式定义。

## 范围说明

全站浏览器回归通过隔离的接口夹具验证布局和空数据状态，首页及项目页包含示例数据。后续使用独立的本地 Django 验证了认证、项目列表和首页核心接口；真实权限组合、增删改查、AI 生成、自动化执行和第三方图表服务仍未完成全面联调。动态详情、复杂编辑及大数据量场景仍需在实际运行环境验收。

通过集中样式入口和两个独立 composable 复用导航与分栏行为，保持现有业务组件和服务职责，避免引入新的生产依赖。

## 首页下半部分专项优化

- 提取 `DashboardInsights.vue`，统一待处理事项、缺陷风险、自动化矩阵、审核分布、Token 使用、执行趋势、运营看板七个区块。移除原首页对应的重复模板、计算属性和样式。
- 桌面采用三张等高重点卡片、审核与 Token 的 1:2 网格、趋势与运营的 2:1 网格；平板调整自动化矩阵位置，手机纵向排列，消除原双卡片占三列造成的空位。
- 统一浅色卡片、分隔线、标题与数字层级，减少嵌套容器和装饰色；深色模式同步调整状态背景色。长用户名和大数值适配窄屏。
- 缺陷风险明确统计口径；APP 汇总未接入时显示“—”和说明；趋势图依据真实传入的通过/失败数绘制堆叠柱，零数据展示空状态。
- Token 日/周/月保持现有接口行为，支持鼠标及键盘切换，用户消耗榜按用量排序。
- 手机端 Token 指标逐行对齐，超大请求数/会话数保持完整数字；趋势图在窄屏保留坐标和柱形，避免柱顶大数值挤在一起，完整数值仍提供文字标签和悬停提示。

专项检查脚本为 `FlyTest_Vue/scripts/verify-dashboard-insights.cjs`，覆盖桌面、平板、390px/320px 手机、空数据、大数值、深色模式共 10 个场景，以及 Token 切换。使用隔离的模拟接口，截图和报告保存于 `FlyTest_Vue/playwright-screenshots/dashboard-insights/`。

最终生产版本验证结果：`npm run build` 通过，专项场景 10/10 通过；卡片对齐、页面溢出、Token 数字完整性、图表标签不重叠、分组接口请求与键盘切换均通过。另对三组桌面区块、深色卡片和手机大数值截图进行了目视复核。
