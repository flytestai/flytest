# 首页质量洞察布局优化

延续已选定的专业浅色风格，对首页下半部分统一处理：待办/风险/自动化三列，审核分布与 Token 资源按 1:2 排列，趋势与运营按 2:1 排列。平板根据内容宽度重新组合，手机纵向排列。

新增独立 DashboardInsights 组件，保留统计接口与分组请求，移除旧下半部分模板、重复计算和装饰样式。卡片采用统一标题、边距、分隔线和数值对齐；红/黄/绿仅表达业务状态；无执行趋势展示空状态，APP 未接入汇总显示破折号。

验证：有数据、零数据、大数字、长用户名；1440/1024/390/320 宽度；深色模式；日/周/月分组请求与键盘操作；生产构建。截图覆盖首页下半部分全部区块。
