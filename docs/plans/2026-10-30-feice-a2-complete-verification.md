# FeiCe A2 全页面补齐验收

日期：2026-10-30。基于用户确认的 A2 明亮方案，补齐上一轮以全局主题覆盖为主、未充分处理业务子页面的问题。

## 实施范围

| 页面类型 | 本轮落实 |
| --- | --- |
| 列表与系统管理 | 共用页头、上下文、操作层级、搜索筛选、表格、分页；项目、用户、组织、Key、MCP、模型及模板页面统一布局 |
| 用例、套件、缺陷 | 目录、工具栏、列表和公共表单接入 A2；行操作使用文字按钮，危险操作保持红色 |
| 用例详情与编辑 | 响应式描述表、按表单实际宽度换列、手机隐藏目录、编辑步骤纵向卡片、详情步骤阅读布局 |
| 需求与报告 | 需求详情、评审和专项报告共用页头；保留返回与版本选择，移除旧渐变和装饰，统一评分及问题区块 |
| API 自动化 | 请求、用例、环境、执行、报告及结构化请求/环境编辑控件；手机配置页签换行，嵌套表单列按容器宽度变化 |
| Web 自动化 | 模块目录、页面、步骤、用例、AI 模式、执行、批量、公共数据、环境、执行器、Trace 及弹层 |
| APP 自动化 | 概览及 11 个业务子页签、弹窗、设置、三栏场景编排、27 类步骤配置及组件库键盘操作 |
| AI、知识与工具 | 对话标题、会话列表、输入区、知识库、Skills、数据工厂七个分类与 51 个工具表单 |
| 公共控件 | 卡片、表单、表格、页签、描述表、弹窗、抽屉、原生输入/按钮、焦点、禁用与错误状态 |

新增共享页头 `WorkspacePageHeader.vue` 和显式组件样式层 `a2-components.css`。业务模板中的 `fc-*` 类承载页面/控件样式，弹层样式同时覆盖 Teleport 至 body 的内容。

颜色继续遵循主操作蓝 #0066FF、通过绿 #008000、风险红 #E00000；执行通过率仅原始值 100% 为绿色，覆盖率 ≥80% 绿色。缺失统计不伪造。

## 同步修复

- 数据工厂分类页首次进入时，在目录尚未加载前被重置为“全部”，导致分类工具不显示。
- 结构化环境编辑器的双向深度监听反复复制并回传相同内容，造成递归更新；加入内容比较，验证新增、编辑及切换配置页签后保留内容。
- 旧文字按钮主题把危险操作覆盖为蓝色；补齐 danger / warning / success / disabled 的独立语义。
- 320px 下工具弹窗中的输入、下拉框和操作区裁切；改为有界布局并减少嵌套留白。
- 用例编辑手机端多列挤压、步骤操作越界、描述表纵向逐字换行。
- APP 编排的大型 AI 状态展示占用首屏；改为可键盘展开的状态区，并为步骤组件补齐 Enter / Space 操作。

## 复现与证据

前端目录中先设置可用的 `PLAYWRIGHT_MODULE`、`UI_BROWSER_CHANNEL` 和 `UI_BASE_URL`，再运行已有脚本及新增脚本：

```powershell
npm run test:workspace:forms
npm run test:asset-details
npm run test:request-editor
```

工具与步骤表单检查需 Python，直接解析仓库中的工具目录和步骤种子定义，不初始化 Django / FastAPI 数据库。`UI_WIDTHS` 可选择表单检查宽度，`UI_TOOLS` 可指定单个工具名称复查。

浏览器截图和 JSON 报告保存在忽略的 `FlyTest_Vue/playwright-screenshots/` 下，主要目录为 `a2-complete-final-*`、`a2-complete-recheck-*`、`a2-workspaces`、`a2-workspaces-recheck`、`a2-asset-details`、`a2-request-editor` 和 `a2-complete-details`。脚本全部使用隔离接口夹具，不向真实业务数据库写入数据。

本地开发前端：`http://127.0.0.1:5175/`；构建预览：`http://127.0.0.1:5176/`。真实模型调用、设备执行、外部 MCP 和具体权限组合仍需实际配置验收。本轮未变更后端或数据库，也未自动提交、推送。
