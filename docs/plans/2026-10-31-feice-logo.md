# FeiCe 标识简化

用户要求：重新设计简约、大气的 Logo，延续后台的专业风格。

## 设计与应用

- 采用单色斜切 F 图形，移除方形底板、对勾、渐变和装饰阴影。
- FeiCe 字标使用自定义 SVG 轮廓，保持各平台的字形和间距一致。
- 标准蓝 `#0066FF`；浅色组合字标为墨蓝 `#1D3151`，深色组合字标为白色。
- 登录页、后台导航、折叠导航、AI 头像、favicon 及兼容 SVG/PNG 路径统一更新；更新资源版本号避免旧缓存。
- 独立标识保持透明背景，移除导航图标的旧背景及 AI 图片的圆形裁切。

## 维护

几何源：`FlyTest_Vue/scripts/generate-brand-assets.cjs`。
执行 `npm run brand:export` 生成全部 SVG 和兼容 PNG，不需要系统字体。

## 验证

已检查 1440 / 390px 登录页的深浅背景、后台深浅背景及折叠导航，并生成 16、24、32、48、64px 图标对照。
预览与页面截图位于 `FlyTest_Vue/playwright-screenshots/brand-refresh/`（不纳入 Git）。

Vue 类型检查与生产构建通过；最终 Vite 打包耗时 40.18 秒。5176 生产预览下的登录页深浅背景、后台深浅背景及折叠导航复核通过。

## 第二轮细化

用户要求继续优化。在同一简约方向上降低 F 主干前倾角度、加入小幅光学圆角，统一字标笔画、修正 C 的上下超出量并收紧字距。
组合宽度从 252 收至 236；图形与字标间距由约 22 收至约 17 个矢量单位；导航字标从 86px 收至 82px。
favicon 使用单独的光学裁框，避免在 16px 下图形因留白而显得过小。深浅组合、兼容 PNG 和缓存版本统一更新。

第二轮 Vue 类型检查与生产构建通过（55.57 秒）；5176 下的深浅色登录页、后台及折叠导航显示复核通过。新版对照图为 `brand-refresh/brand-refined-preview.png`。
