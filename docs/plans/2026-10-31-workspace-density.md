# 工作区布局密度优化

用户反馈：上一轮目录重构后，后台页面仍不够紧凑。继续沿用 A2 配色、圆角和风险语义，不改变业务接口。

## 实施

- 合并目录入口、范围提示、标题及操作区，移除单独占一行的目录横条。
- 用例列表将四类筛选收入可展开面板，显示启用数量；导入、导出合并为菜单。
- 接口执行选中、集合、项目三个范围收入“执行测试”菜单；小屏搜索与环境并排，元信息使用通栏。
- 桌面缩小外部留白、表格单元格及工具栏内距；移动端保留原有触控尺寸。
- 首页指标采用标签、数值与说明的紧凑排版；宽工作区的待办改为双列。
- 缺陷状态改为横向指标，详情元信息使用分隔线，减少字段卡片的嵌套。

## 验证

- `scripts/verify-workspace-density.cjs`：1440、1024、390、320 屏幕下测量首屏位置，检查溢出、筛选状态和菜单入口；可用 UI_POPULATED 验证长列表。
- 上一轮 contextual workspace 用例覆盖目录、筛选及编辑交互。
- Vue 类型检查与生产构建。

截图和测量报告位于被 Git 忽略的 `FlyTest_Vue/playwright-screenshots/density-*` 目录。

## 已完成结果

- 1440×900 用例表格顶部由 280px 提前至 153px，首页指标高度由 127px 收至 110px。
- 重点目录与交互回归：1440、1024 各 23 项；390、320 各 23 项，共 92 项通过。
- 四种宽度共 20 个页面布局检查无横向溢出；长列表使用浏览器隔离的 30 条环境数据，未修改业务库。
- 最终生产构建通过（1954 个模块，50.99 秒）；5176 预览下 1440、320 两种宽度的 10 个页面检查通过，同时验证筛选保留、导入导出和执行范围菜单。
