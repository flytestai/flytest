# AI 对话参考图布局

**目标：** 按用户参考图实现页头、历史会话、上下文工具栏、欢迎引导和底部输入区；保留项目隔离、流式消息、知识库、多模态及工具审批。

1. 对话页头移至工作区外，展示 AI 图标、说明、当前项目与新对话；复用目录的折叠、拖拽宽度和手机抽屉交互。
2. 历史会话支持搜索、今天/最近 7 天/更早分组，默认隐藏批量复选框，保留删除确认与批量管理。
3. 顶部工具栏保留项目、知识库开关、提示词、模型配置、工具审批；使用图标替代装饰性 emoji。
4. 欢迎区采用品牌标识、标题、说明及三个任务卡片。卡片只预填草稿，不自动发送。
5. 输入区采用上下两层，保留引用、图片预览、Token 状态、停止生成；新增图片选择入口及模型状态。后端不支持任意文件或工具选择参数，因此不虚构文件上传及工具选择能力。
6. 无模型时保留草稿并引导配置，中文输入法确认不会误发；验证四种宽度、历史搜索/切换、配置入口、快捷草稿、发送/停止和错误状态。
7. 执行类型检查、生产构建、隔离夹具与真实页面验证；本轮不提交或推送 Git。
