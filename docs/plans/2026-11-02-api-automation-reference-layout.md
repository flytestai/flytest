# 接口自动化参考图重构计划

**目标：** 统一接口目录、测试用例、环境配置、执行记录、测试报告五个子页，采用紧凑的浅色工作区和详情侧栏。

**实现：** Vue 3 / Arco Design；复用现有请求编辑、环境编辑、执行与报告 API。共享指标和操作容器通过工作区上下文传递，保留现有状态及未保存提醒。

1. 建立共享标题、指标、页签及响应式详情容器。统计基于真实接口数据，失败或未加载显示占位；无在线检测能力时展示配置情况。
2. 接口目录保留树与请求编辑，新增真实配置概览和字段说明侧栏，响应与断言并排展示；不伪造 AI 建议。
3. 测试用例改为紧凑列表与侧边详情，提供状态、执行结果筛选，保留批量执行、生成和编辑。现有后端只有草稿/就绪/停用，以“设为就绪”操作对应真实状态，避免伪装审核功能。
4. 环境配置改为列表＋详情，展示真实变量/公共头，密钥默认遮蔽，编辑与保存复用现有结构化编辑器。
5. 执行记录以紧凑表格呈现，右侧查看真实请求、响应、断言、工作流和失败复盘；不编造执行阶段耗时。
6. 测试报告优先展示趋势、结果分布、失败接口和错误分类，再保留批次和详细统计；AI 摘要必须用户触发并显示实际返回来源。
7. 验证 1440 / 1024 / 390 / 320px、空/有数据、筛选、详情、保存和执行；完成类型检查、构建及真实账号访问，不提交或推送 Git。

## 完成与验收

- 五个子页均使用共享页头、真实指标和页签；主操作通过工作区容器呈现，切换子页不会遗留其他页的按钮。
- 请求调试采用目录、请求编辑/响应、配置概览；字段类型由当前 JSON 推断，并标明实际约束来自契约/断言。
- 用例、环境、执行记录改为紧凑表格与侧栏；窄屏使用抽屉。用例新建接入已有 POST 接口，就绪操作接入既有状态更新。
- 环境密钥默认遮蔽，显隐和编辑使用原值；环境修改同步其他页的选项，保留有效的当前选择。
- 报告展示红绿趋势、分布、失败排行和近期错误样本；AI/规则摘要明确实际来源，并丢弃已过期筛选范围的异步结果。
- 四种屏幕宽度及通过率边界、报告错误恢复共 24 项检查通过；原有未保存提醒、请求执行、AI 断言草稿等回归 6 项通过。
- 最后补查 1440 / 320px 共 14 项；根据截图修正侧栏独立滚动、固定详情标题及基础地址列宽，并单独验证这些交互。
- 真实账号访问五个子页无接口错误，后端 OPTIONS 确认支持用例创建；类型检查与生产构建通过。未提交或推送 Git。
