# 本地服务与透明滚动条

## 界面调整

纵向、横向滚动条的轨道、滑块和交汇角统一透明，包括弹窗、抽屉、Arco 自定义滚动条及 Monaco 编辑器。保留滚动容器、滚轮、键盘和触摸滚动能力，不使用 `overflow: hidden` 或清空滚动条尺寸。

`npm run test:workbench:scrollbars` 覆盖工作台、APP、知识库、权限页，1440 / 390px，深浅主题，共 16 项检查。

## 当前本地服务

| 服务 | 地址 / 用途 |
| --- | --- |
| Django ASGI | `127.0.0.1:8001`，主 API 与 WebSocket |
| APP FastAPI | `127.0.0.1:8010`，内置任务调度器 |
| Redis | `127.0.0.1:6379`，队列、结果和 Channels |
| Celery Worker | 消费 `celery`、`ui_automation` 两条队列 |
| Celery Beat | 周期任务调度，状态文件保存在 `service_logs/` |
| Qdrant | `127.0.0.1:8918`，向量存储 |
| FeiCe MCP | `127.0.0.1:8006/mcp`，使用本地专用凭据 |
| Playwright MCP | `127.0.0.1:8931/mcp`，隔离的无头浏览器 |
| Web 执行器 | `feice-local`，连接 Django WebSocket |
| 前端 | 开发 `5175`，生产预览 `5176` |

本机 `8000` 属于其他程序。本项目通过前端 `.env.local` 指向 `8001`，没有停止该程序。Vite 配置现在同时读取环境文件和进程变量，开发与生产预览均生效。

在仓库根目录可重新启动已经准备好的本地运行环境：

```powershell
./deploy-scripts/start-local-services.ps1
```

脚本复用记录中的存活进程，遇到未管理的占用端口会报错；后台窗口隐藏。运行时程序、独立 Python 环境、进程记录、执行器配置和凭据均保存在 Git 忽略的 `service_logs/`。该脚本不下载依赖、不初始化业务数据库，适用于已准备运行环境的本机。

## 执行器修复

WebSocket 协议层 ping 不会进入 Django Consumer，原来空闲执行器在 90 秒后被误判离线。客户端现在每 30 秒发送独立的应用层心跳，任务消息处理期间也持续更新在线租约，停止时取消心跳任务。自动化测试覆盖繁忙处理和断线停止，并对真实连接进行了超过 90 秒的空闲在线验证。

## 外部能力与配置边界

本地数据库没有配置 LLM。AI 生成、分析以及需要外部嵌入/重排模型的检索，需要配置真实服务和有效凭据。ADB 工具可用，但目前没有连接 Android 设备。外部 MS 平台集成也需要目标地址与凭据；不使用示例地址宣称集成成功。

本地验收结果、服务日志及真实页面截图保存在 `service_logs/`；生产构建包含 Vue / TypeScript 检查。
