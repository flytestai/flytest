# 深蓝青绿前端验收记录

## 范围

依据用户提供的登录、质量工作台、测试资产与接口自动化设计稿实施。全站共用深蓝导航、浅色工作区、青绿主操作、紫色 AI 标识和统一控件。原有质量指标红绿阈值保持独立。

重点变化：

- 登录和注册共享分栏认证布局、青绿飞翼品牌与帮助入口；小屏缩短品牌区。
- 工作台保留四项指标与统计风险摘要，新增真实高风险缺陷、个人待办、环境/执行器/设备状态；趋势支持通过率与执行量。
- 用例目录、列表和详情审核三栏；低于 1280px 使用详情抽屉；审核状态与执行结果独立展示。
- 接口目录直接打开请求工作区，复用已有配置、保存和执行服务；响应与断言并列展示。AI 草稿人工确认后才添加至编辑器，保存前不落入接口，且不调用用例生成任务的 apply 接口。
- 需求、知识库、数据工厂、API/Web/APP 子页、项目、团队和系统配置页共用主题与响应式控件。

## 复现

在 `FlyTest_Vue` 中设置 `UI_BASE_URL`、`PLAYWRIGHT_MODULE` 与浏览器通道后运行：

```powershell
npm run test:layout
$env:UI_WIDTH = "390"
npm run test:layout
Remove-Item Env:UI_WIDTH
npm run test:auth
npm run test:quality
npm run test:request-editor
npm run test:asset-details
npm run test:workbench
npm run test:workbench:state
npm run test:dashboard
npm run build
```

截图与 JSON 报告位于被 Git 忽略的 `FlyTest_Vue/playwright-screenshots/`。README 中的界面图来自实际浏览器渲染及隔离场景，不代表真实项目数据。
