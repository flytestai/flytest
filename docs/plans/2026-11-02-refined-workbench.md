# FeiCe 整站精修实施计划

**目标：** 保留深蓝导航、浅色工作区、青绿操作与紫色 AI 语义，提升内容层次、排版品质与移动端效率。

**实现方式：** 在现有共享组件和主题文件中调整，避免新增整站覆盖层。业务接口、权限及现有数据保持原有契约；本轮不提交或推送 Git。

## 1. 共享结构

- `WorkspaceModuleHeader.vue` 增加当前页面标题和手机全部导航；保留桌面标签及键盘访问。
- `WorkspacePageHeader.vue`、`WorkspaceDirectoryLayout.vue` 使用紧凑子页标题契约，避免模块和子页标题重复。
- APP、Web、接口和资产视图接入统一标题体系。

## 2. 视觉规范

- 在现有主题文件中统一 26px 页面标题、16px 区域标题、14px 正文、12px 辅助信息。
- 保持面板 12px、控件 8px 圆角，标准控件 36px，密集表格 32px，手机主要操作 44px。
- 减少嵌套面板、表格竖线和装饰性阴影；统一操作区与内容边界。
- 保留红绿质量阈值、紫色 AI 与透明滚动条。

## 3. 主要页面

- 登录：优化品牌版面、飞翼比例、表单尺寸和反馈。
- 工作台：收紧指标与空状态，让风险和待办在首屏更易访问；规则汇总使用“质量摘要”。
- APP：合并标题与状态操作，手机双列指标，AI 未配置提示简化，加载状态不误报异常。
- 资产/API：保留可伸缩目录与详情，减少重复标题和内层边界。
- 知识库/权限/其他管理页：优化起步引导、空状态和紧凑信息列表。

## 4. 验收

- Vue/TypeScript 与 Vite 构建。
- 1440、1024、390、320px：主要入口、目录与详情、表单、弹窗和真实服务。
- 手机模块导航与指标密度、加载状态、AI/质量颜色及透明滚动条。
- 截图复核登录、工作台、资产、API、APP、知识库及权限页面；更新验收记录。

## 5. 已完成的精修

- 共享模块标题显示当前页面，目录工作区仅保留一套标题；局部编辑页和返回操作保留自身上下文。
- 手机模块栏提供“全部”菜单，支持当前项标识、方向键、Home/End、Enter 与 Escape；保留横向标签导航。
- 调整登录页品牌与表单比例，统一控件尺寸、正文可读性及圆角。
- 工作台统一卡片比例，将规则汇总准确命名为“质量摘要”，通过率与执行量视图均采用标准红绿柱状图。
- APP 自动化收紧状态与操作区，手机双列指标；尚未完成健康检查时显示“正在检查服务”，未配置 AI 时聚焦配置入口。
- 知识库和权限页采用简洁起步状态；知识库支持直接创建与清空筛选。
- 用户搜索框适配 320px 窄屏；服务状态使用平面信息网格，减少嵌套卡片。
- 在现有共享组件及主题文件内维护规则，新增空状态组件复用于知识库和权限页，避免为每个页面复制一套结构。
