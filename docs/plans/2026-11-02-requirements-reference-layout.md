# 需求管理参考图布局实施与验收

**目标：** 按用户提供的参考图重排需求管理页，保持深蓝导航、浅色工作区、青绿操作与紫色 AI 入口。

**实现：** Vue 3、Arco Design，复用现有需求文档、项目成员和评审接口。只调整需求管理及其类型契约，不更换全站框架，不提交或推送 Git。

1. 页面顶部采用图标、标题、说明与上传/新建评审双操作；以轻量 SVG 波形建立背景层次。
2. 项目级四张统计卡片（需求文档、评审任务、待分析、已完成评审）与 AI 助手入口。统计独立于列表搜索和分页，未获取到数据显示占位而非伪造数字。
3. 需求文档、评审记录、分析报告三个页签分别展示全部文档、已有评审的文档和已完成评审的文档；每行保留详情、拆分、评审、报告、重试等真实操作。
4. 独立筛选栏提供搜索、状态、类型、上传者及重置；空状态区分无文档、无匹配记录、未开始评审和未生成报告。
5. 新建评审先选择待评审文档，再进入现有评审配置；AI 助手链接已有 AI 对话页面。
6. 覆盖 1440、1024、390、320px；验证页签、筛选、统计、上传校验、新建评审、报告跳转、空状态与错误恢复。执行类型检查和构建，保存截图与验收结果。

**数据语义：** 后端未提供测试建议总量与独立负责人字段，分别使用真实的已完成评审数、上传者。列表的评审进度使用真实状态文字，不虚构百分比。

## 最终验收

- Vue/TypeScript 类型检查和 Vite 生产构建通过。
- 开发版本与最终生产版本均通过 13/13 个布局和交互检查，覆盖 1440、1024、390、320px。
- 验证空状态与有数据列表、项目级统计不随搜索改变、评审/报告页签、键盘切换、组合筛选和重置、新建评审配置、列表错误恢复。
- 上传弹窗改用提交前校验：校验或上传失败时保留弹窗与输入，上传成功后关闭。隔离夹具验证失败保留输入和成功提交的内容请求，未向真实业务库写入测试文档。
- 真实账号登录、需求统计、三个页签、新建评审选择器及手机边界验证通过；没有 API 错误响应或页面脚本异常。当前验证项目为空，统计显示真实的四个 0。
- 真实验证首次读取到了项目加载前的占位值；改为等待统计实际完成后复验通过。
- 页面专属样式使用局部命名及 scoped CSS，清理旧英雄区和重复覆盖规则，不影响其他业务页面。
