# APP 设备管理参考图落地

- 范围：设备管理独立页面，保留 APP 子导航与现有连接、编辑、截图、锁定和释放能力。
- 结构：设备标题横幅；五项互斥设备状态统计及在线率；筛选、批量操作、完整宽表与分页。
- 数据：统计基于完整设备池，筛选和分页在客户端完成。在线率只计算 available/online，不把忙碌状态重复计入。空设备池显示暂无数据。
- 元数据：按 device_specs 中平台、型号、系统与模拟器标记统一呈现 Android / iOS；未上报使用率不显示伪造百分比。旧服务以 android_version 识别 Android。
- 操作：添加设备沿用真实 ADB 网络连接与发现；启动测试跳转用例页并预选设备；iOS 在当前 Android 执行服务下不提供虚假的执行能力。批量锁定/释放汇总逐项结果，仅操作满足条件的选中设备。
- 适配：桌面单行统计与完整表格；中屏统计换行；手机筛选纵排，宽表在面板内横向滚动，保留全部字段。
- 验证：类型检查与构建；多尺寸截图；状态分类、空态、筛选不改变统计、缺失遥测、分页与选中状态、真实入口与批量部分失败。

## 验证结果

- Vue 类型检查与生产构建通过。
- 生产预览设备页面 12 项隔离检查通过，覆盖 1672/1280/768/390/320 像素。
- APP 概览桌面及手机回归通过，保留原有概览布局和旧接口兼容能力。
- 真实登录后设备列表接口 HTTP 200，页面总量与服务返回一致；当前本地设备池为空，正确显示空态和无在线率。真实验收未执行设备写操作。
