# APP 执行记录参考图

- 统一标题横幅、执行总数/通过/失败/异常指标与近 7 天趋势。
- 全量项目指标不随分页/筛选变化，筛选结果总数单独展示；一行对应一个真实执行 ID，套件执行不伪装成一次套件汇总任务。
- 筛选包含名称/编号/错误、来源、结果、应用、设备、套件、任务与日期。任务按明确 task_id 或任务最近执行的精确 ID 列表关联，不把所有定时执行推测为某个任务。
- 历史应用版本仅读取执行快照；当前用例的应用关联以“当前关联”标注，旧数据缺少版本显示未记录。
- 状态互斥，运行/等待优先；明确 error/exception 计异常，failed 计失败，停止单独显示。不依靠错误文本猜测异常类型。
- 趋势使用 UTC 日期，最近 7 日明确通过/失败/异常的完成结果；无数据留空，100% 绿色，其余红色。
- 保留停止执行、自动轮询、路由直达详情、报告和证据文件；日志提供独立直达入口。
- 使用隔离接口检查筛选、边界日期、分页、日志、报告、空态/错误和 1672/1280/768/390/320 像素。
