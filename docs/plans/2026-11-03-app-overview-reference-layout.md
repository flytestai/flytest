# APP 自动化概览布局

按用户提供的参考图实现：品牌横幅、模块导航、六项指标、执行趋势与设备状态、我的待办与 AI 助手。沿用深蓝导航、浅色工作区、青绿操作、紫色 AI。

- 指标为设备总数、应用包、测试用例、执行总数、通过率与待处理缺陷。设备属于共享资源；缺陷明确标注当前项目范围。
- 概览统计接口增加只读的近 30 天按日聚合与互斥设备状态分组，避免前端下载全部执行历史。
- 趋势支持 7 / 30 天，执行量用柱状、通过率用折线。通过率从通过与失败计数计算，只有严格 100% 为绿色，无完成结果为中性。
- 待办来自定时任务、执行报告和项目缺陷，入口链接真实页面；保留任务操作及最近执行明细。
- AI 助手读取真实模型状态，提供场景编排与模型配置入口，不展示示例任务或虚构增长值。
- 适配宽屏、平板与 390 / 320 像素手机；保留加载、错误、重试及空状态。
- 验证统计聚合的项目隔离与设备互斥分组，进行类型检查、生产构建、界面和真实接口回归。

本次不执行 Git 提交或推送。

本地运行服务保持原进程；前端对旧统计接口提供真实只读数据兼容，后端新增聚合在下一次常规服务启动时生效。

## 验证结果

- 类型检查与生产构建通过，5176 预览已更新。
- 11 项生产界面检查通过：四种屏宽、时间范围切换、严格通过率颜色、失败重试、空状态、旧接口兼容及缺陷统计不可用状态。
- 2 项隔离后端测试通过：统计的项目隔离、设备互斥分组、空日期补齐与无执行结果。
- 实际账号验证概览、设备／历史执行兼容取数及项目缺陷统计；缺陷指标跳转通过。未修改业务数据。
