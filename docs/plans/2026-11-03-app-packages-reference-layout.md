# APP 应用包页面

- 按参考图使用独立横幅、五项指标、安装率、组合筛选与完整应用包列表，延续设备页圆角与青绿配色。
- 统计基于当前项目完整列表，不随筛选变化；版本和安装情况未知时显示未上报，不推测为未安装。
- 保留现有应用记录 CRUD，新增按项目权限保护的 APK/AAB/IPA 文件上传、下载及元数据接口。文件独立归档，无需改动现有数据库表结构。
- 版本由上传时填写，不声称已解析二进制清单；只有上传成功才保存文件元数据。安装状态是当前归档版本的实际安装任务记录，不代表已完成设备全量盘点。
- APK 经 ADB 安装到在线空闲 Android 设备；安装期间保留设备锁，成功才显示完成。AAB 需转换，IPA 需 iOS 驱动，不提供虚假安装进度。
- 旧服务没有文件接口时仍可编辑应用记录，明确提示文件服务尚未部署，避免把元数据保存等同文件上传。
- 验证：隔离 API 测试、平台/版本/文件筛选、批量结果、项目切换竞态、五档屏幕、类型检查、生产构建及真实只读验收。
