# APP 测试套件页面

按照用户参考图采用标题横幅、四项统计与 AI 卡片、业务分组目录和紧凑套件表格，复用测试用例页的视觉规范。

- 原有详情、历史、报告、排序、复制、删除和顺序执行保留。
- 分组与策略通过 APP 服务元数据扩展保存到受项目限制的本地侧文件，不更改现有数据库结构；旧接口能力不足时明确提示并禁用对应配置。
- 并行执行使用多台 Android 设备，按用例顺序轮流分配队列，每台设备内顺序运行，各设备之间并行。事务内统一预留设备，失败时回滚，避免在同一台设备竞争执行。
- AI 规划只从现有候选用例选择编号并排序；用户采用建议、编辑和保存后才创建套件，不自动执行。最多 200 条候选，可按名称/标签缩小范围。
- 通过率按当前服务返回的已完成套件结果计算，仅 100% 为绿色；近 7 天执行量为套件内用例执行记录数，清楚标注口径。
- 使用隔离 API、临时数据库与模拟执行器验证，不操作真实设备；保留当前服务进程，不重试此前被阻止的服务重启。
