# APP 测试用例参考图

- 延续 APP 子页共用的导航与标题横幅。
- 五个统计卡片与 AI 入口；指标来自当前项目完整列表，不随分页或筛选变化。
- 左侧用例分组搜索、全部用例与分组计数；右侧搜索、优先级、结果、套件筛选及紧凑表格。
- 分组和优先级使用现有 `ui_flow.feice_meta` 扩展信息，保留已有扩展键和标签；旧数据明确为未分组、未设置优先级。
- 现有后端没有禁用字段，因此使用空流程统计；可执行表示具有步骤，不表示设备就绪。套件读取真实关联，不杜撰负责人或更新人。
- 保留快速编辑、场景编排、复制、删除限制、单用例执行和套件批量执行入口。
- JSON 导入先预览再确认，绑定当前项目，跳过同名项，失败可重试；导出选中项或筛选结果。
- AI 入口进入现有场景编排生成对话框。错误状态、移动端、保存失败及元数据保留需验证。
