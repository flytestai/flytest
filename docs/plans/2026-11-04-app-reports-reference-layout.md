# APP 执行报告参考图落地

- 六项真实指标、执行结果分布、七天通过率趋势、报告列表与右侧联动详情。
- 现有服务一条执行对应一份报告；不将套件当前成员或多个历史批次拼成虚构的批次报告。
- 区分执行结论、步骤通过率、执行次数和报告数；未知步骤数据不填充为用例数，运行中不计入已完成通过率。
- 保留套件概览、原有详情、执行证据及完整 HTML 报告入口，新增筛选结果/所选报告摘要 CSV 导出。
- 通过率仅 100% 为绿色；低于 100% 为红色，无数据为中性；未知应用历史版本不以当前版本冒充。
- 筛选支持名称/执行或任务编号/套件、来源、结果、本地日期；项目切换清理选择并防止旧异步响应覆盖。
- 隔离验证统计口径、状态优先级、日期边界、导出、详情/完整报告、多屏幕布局。
