# APP 环境设置参考图落地

- 五项环境概览、项目环境列表与筛选、右侧连通健康图、环境操作和使用指引。
- 新增项目级配置注册表与 CRUD/批量维护/克隆/原子导入，保存为服务端 JSON，不改变数据库结构。
- 新环境初始待检测，维护状态独立于检测；配置变更使旧检测失效；克隆及导入均不沿用健康结果。
- Android 使用 ADB 实际设备列表检测；服务地址仅做 TCP 连通检测；云设备/iOS 未接入能力显示未知，不伪造可用。
- 配置启用与维护不启动/停止实际设备或服务；当前执行仍以任务设备及全局执行器配置为准。
- 原全局 ADB、路径、依赖及服务诊断收纳至执行器配置面板；旧服务未加载注册表接口时明确提示并展示真实当前配置。
- 验证项目隔离、原子导入、健康失效、未支持能力、交互失败保留、导出及五种宽度。
