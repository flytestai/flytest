## 实现与验收

- 新增 GET `/api/knowledge/knowledge-bases/workspace/?project=...`，按项目成员权限汇总，统计不受分页和搜索影响，无数据库迁移。
- 本月检索按服务端配置时区的自然月计算；热门检索按最近 30 天查询日志聚合，不生成示例主题。
- 接入分布按本地文件、网页链接、文本内容互斥分类；片段数仅统计有 vector_id 的分块，不代表实时向量服务健康状态。
- 状态为启用中、文档处理中、停用；停用且仍有文档处理的知识库归入停用，避免重复计数。
- 保留全局导航下 `/knowledge-management` 的独立入口，不向 APP 子导航重复添加知识库。
- 详情、统计、创建编辑、全局配置复用原组件；快捷上传先选择目标知识库，表单校验和保存失败不会关闭弹窗。
- 修复上传弹窗的模拟进度计时器，改用真实请求 loading；编辑时保留并允许修改启停状态。
- 后端隔离测试：`FlyTest_Django/.venv/Scripts/python.exe manage.py test knowledge.test_workspace --noinput`（在 Django 目录执行），4 项通过。
- 前端浏览器：`npm run test:knowledge:reference`，11 项通过，含 1672 / 1440 / 1024 / 768 / 390px。
- 浏览器使用隔离接口夹具验证交互；后端使用独立测试数据库，不修改实际项目或上传真实文件。
- 旧服务未加载 workspace 接口时，概览显示不可用提示及破折号，列表仍使用原接口；真实部署需加载新 Django 代码。
