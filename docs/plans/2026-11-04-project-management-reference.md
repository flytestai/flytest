# 项目管理参考图落地

- 保留 `/projects` 入口及项目创建、编辑、成员管理、删除申请审批流程。
- 实现五项概览、紧凑筛选表格、右侧协作环图、最近项目更新及权限说明。
- 仅使用已有接口，不新增数据库状态字段或伪造草稿/归档状态。活跃度以近 30 天项目更新时间为依据。
- 项目总数与近期更新覆盖全部可见项目；团队成员按当前页用户 ID 去重；测试资产为当前页手工/API/Web 用例数，明确标注统计范围。
- 当前页成员和资产以有界并发加载，失败显示破折号；切页/刷新后过期响应不回写。
- 搜索名称、描述、ID；按创建人和活跃度筛选；按更新时间/名称/创建时间排序；客户端分页适配现有非分页项目 API。
- 最近更新来源于真实更新时间，不冒充审计事件；权限说明展示现有角色规则，不提供无接口的归档或复制操作。
- 验证筛选分页、创建/编辑失败保留表单、成员管理、删除审批入口、无权限及小屏布局，执行正式构建。

## 实现及验收

- 页面拆为项目管理容器、展示组件和纯统计/筛选函数；继续使用原项目、成员、统计及删除申请接口，无数据库迁移或新增接口依赖。
- 名称入口进入所选项目工作台；用例资产入口切换所选项目并打开测试资产；成员、编辑及更多操作保持独立。
- 成员和资产只加载当前页，最多同时处理三个项目，迟到响应由请求版本隔离。成员读取失败或任一资产分类不可用时，汇总显示破折号，不当作零。
- 搜索、创建人、活跃度、排序和分页在现有完整项目列表上统一处理；列表加载失败不使用缓存掩盖失败，也不显示虚构总量。
- 成员拥有者/自身角色操作禁用；新增成员与角色更新改为 before-ok，校验或请求失败保留表单。
- 删除弹窗明确是提交审核，并提供取消按钮；项目创建/编辑后同步全局项目选择器。
- 修正全局表格字号/内边距覆盖，保证桌面时间、创建人及全部操作按钮可见；手机表格在自身容器内横向滚动。
