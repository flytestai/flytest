# 用户管理参考图实现

- 新版独立页头、全部/待审核/启用/管理员四项概览、审核状态导航、组织/角色/账号/审核筛选、紧凑用户信息表格。
- 保留现有添加、编辑、权限树、审核和操作日志；新增只读详情面板和明确确认的账号启停操作，使用原 updateUser 接口。
- 组织来自真实用户组；手机号列表脱敏；最近登录仅展示真实 last_login，未返回则标明未提供。
- 暂无批量导入接口，导入入口提供真实能力说明和添加用户替代入口，不实现隐式批量账号创建。
- 不生成周增长示例数据；统计覆盖完整可读取列表，不受分页或当前筛选影响；禁用与审核是独立维度。
- 修复原表单 validate 返回错误对象仍发送请求的问题；新增/编辑失败保留表单，敏感操作有取消与失败反馈。
- 当前登录账号禁止通过本页快捷禁用/删除，编辑自己的管理标识和启停选项禁用；审核、权限分配与启用互不自动联动。
- 隔离夹具验证浏览器交互，使用边界测试验证筛选与统计；适配五种宽度并完成正式构建，不修改真实用户权限。
